# ب · الوضع الداكن ألوان خاصة به (اختياري)

## «ألوان مختلفة للوضع الداكن»
مفتاح · الافتراضي: مطفأ

**الوظيفة:** عند التشغيل تُستخدم الحقول التالية في الداكن، وتصير ألوان (أ) للفاتح فقط.
