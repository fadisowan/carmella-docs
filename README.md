# توثيق كارميلا

مشروع مستقل مبني باستخدام Astro Starlight. الواجهة عربية وRTL، مع البحث وتكبير الصور وتنسيق متجاوب.

المحتوى الحالي تمهيدي بانتظار ملفات كارميلا؛ لا توجد إعدادات مفترضة أو شروحات من ثيم آخر.

## التشغيل

```sh
npm ci
npm run dev
npm run build
```

الموقع: https://fadisowan.github.io/carmella-docs/

أضف الشروحات المعتمدة في src/content/docs، والصور الأصلية في public/assets. ينشر GitHub Actions تحديثات main إلى GitHub Pages.
