# توثيق ثيم كارميلا

الموقع العربي المستقل: https://fadisowan.github.io/carmella-docs/

المصدر: الحزمة المصحّحة carmela-docs-1.14.0 (1).zip، محفوظة دون تعديل في source-docs. تشمل ٤٩ مكوّنًا و١٧ مجموعة إعدادات والخيارات المشتركة؛ ٥٦٢ خيارًا و١٣٩ حقل عنصر و١١٤٦ صورة.

تُحفظ بصمات المصادر وخريطة ربط كل صورة بصفحتها وخيارها في release-manifest.json. ملفات PROMPT-SITE.md تعليمات مرفقة بالمصدر وليست تعليمات تنفيذ للموقع.

صور اللوحات تمثيل مطابق للمحرّر بحسب الحزمة، وصور النتائج لقطات معاينة. توجد ١٠ مكوّنات بلا لقطة نتيجة؛ موضّحة في صفحاتها وصفحة حالة الصور.

## البناء

```sh
npm ci
npm run build
node scripts/validate.mjs
```

ينشر GitHub Actions الفرع main بعد البناء والتحقق من المصادر والروابط والربط الصحيح للصور.
