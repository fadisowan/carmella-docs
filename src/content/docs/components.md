:::note[هذا القسم قيد الإعداد]
سيُضاف محتوى مكوّنات الثيم بعد استلام ملفات كارميلا، مع الصور الأصلية وربط كل شرح بمكانه الصحيح.
:::

لا توجد إعدادات أو صور معتمدة مضافة لهذا القسم حتى الآن.
